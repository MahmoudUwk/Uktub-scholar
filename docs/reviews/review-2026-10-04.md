## Executive Summary

All 10 review areas have been executed against live services, real scientific papers (`test_papers/`), and local GPU/CPU runtimes.
- **594/594 test suite passes** (2 skipped by design: env-gated Julia adapter).
- **2 Critical Bugs Discovered & Fixed in TEI Parser**:
  1. OpenAlex Content API GROBID TEI was failing due to case sensitivity and HTML tag wrapping (`<html><body><tei>`), breaking TEI acquisitions. Fixed in `src/core/source/extract.ts`.
  2. Long direct text inside `<div>` (> 200 characters) was silently discarded rather than preserved as body text, causing document truncation or spurious `no_text_layer` refusals on unstructured TEI. Fixed in `src/core/source/extract.ts`.
- **1 Robustness Flaw Discovered & Fixed in Managed Runtime**:
  - The supervisor only attached `process.once("exit")`. When the parent Node process received termination signals (`SIGTERM`, `SIGINT`/Ctrl+C, `SIGHUP`), the child `llama-server` process was orphaned and remained running indefinitely on loopback. Fixed with active signal listeners in `src/core/embed/runtime.ts`.
- **1 Architectural Improvement Delivered**: Discovered and pinned first-party, ungated `ggml-org/embeddinggemma-300M-GGUF` (`embeddinggemma-300M-Q8_0.gguf`, 316 tensors), replacing reliance on third-party conversions and achieving **0.9997 cosine parity** against reference `sentence-transformers`.
- **Eos Decision 2.0 Claim Verification Evaluated**: Verified 40 TRUE claims (95.0% recall) and 30 FALSE claims (96.7% specificity, 1 FP / 30, 97.4% precision) running locally on CUDA RTX 4060 GPU with 100% pointer resolution and exact containment compliance.

### Item 3: Registration & Sources on Real Papers
- **Status:** PASS
- **Scripts:** `scripts/test-live-registration.ts`, `scripts/test-live-tei.ts`
- **Real Identifiers:**
  - Registered Nature AlphaFold paper (`10.1038/s41586-020-2649-2`), arXiv preprint (`arxiv:2411.09996`).
  - Aliases tested: Registering `https://doi.org/...` followed by raw DOI correctly flagged as `duplicate`.

  - Identity mismatch guard: attaching an unrelated PDF to a registered paper threw `identity_mismatch` and preserved original source.
  - Keyless acquisition: PeerJ paper with only landing page correctly refused `no_open_copy` without illegal scraping.
- **GROBID TEI Content API Live Path & Critical Bug Fixes:**
  - Exercised OpenAlex Content API on DESeq2 (`10.1186/s13059-014-0550-8`), U-Net (`W1901129140`), and PRISMA (`W2156098321`).
  - **Bug 1 Discovered:** Content API returns GROBID TEI wrapped inside `<html><body><tei...>` with lowercase XML tags and section titles as leading `#text` under `<div>`. The existing extractor did case-sensitive `<TEI` regex, looked for `<teiHeader>` instead of `<teiheader>`, and dropped leading text under `<div>`.
  - **Bug 2 Discovered:** Direct text inside `<div>` longer than `MAX_SECTION_LABEL_CHARS` (200 characters) was silently discarded rather than preserved as body text, causing data loss or spurious `no_text_layer` refusals on documents with long introductory sections.
  - **Fixes Applied:** In `src/core/source/extract.ts`, made TEI root detection case-insensitive (`/<tei[\s>]/i`), relaxed XML tag search in `find()`, captured initial `div` text nodes <= 200 chars as heading marks (`head: true`), and preserved all long or subsequent text inside `div` as body blocks (`head: false`). Behavioral unit tests added to `tests/source-extract.spec.ts`.

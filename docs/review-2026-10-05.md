## Detailed Evidence & Logs

**1. Baseline.** First `pnpm test` failed `embed-runtime.spec.ts:334` ("absolute member": `ENOTEMPTY` from `rmSync` at
`runtime.ts:307`). Reproduced 1/30 isolated and 1/10 full runs. Root cause read from tar 7.5.22: `warnMethod` turns every warning
(including the *informational* "stripping `/` from absolute path") into `emit('error')` under `strict`, and `extract({file})` rejects
on `error` but only resolves on `close`. After the fix: 0/40 isolated, 0/10 full.

**2. MCP.** Probe spawned `bin/uktub-scholar.js mcp` as a child. Bare, `mcp__uktub_scholar__`, `uktub-scholar/`,
`mcp__uktub-scholar:` and `uktub_scholar__` prefixes all route; `nope_tool` and `mcp__other__…` return `Unknown tool` as `isError`.
Success results carry `structuredContent`; refusals do not (consistent). `arguments: ["x"]` is rejected by the SDK with
`-32603` and a raw zod dump (not a stable refusal; low). Signals to the bin shim (`spawnSync` wrapper) killed the real server too.

**3. Host config.** `claude/pi/cursor/agy/opencode/codex` clean installs valid; merge kept `weather-server`, `fetch` (with `env`)
and unrelated top-level keys; re-run produced identical sha256. Malformed JSON refused and not clobbered. Not defects, recorded
as limitations: JSONC with comments and a zero-byte file are refused; the codex branch matches `[mcp_servers.uktub-scholar]` by substring and prints "Wrote …" even when it skipped.

**4. Confinement.** `attach` refused 17 hostile inputs: `..` (×4, one backslash form), absolute (×2), file symlink and `/etc/passwd`
symlink out of the project, directory symlink, FIFO (no hang), `.git/`, `.registry/` (×2), `sub/../.git`, directory, NUL byte, empty path. `mcp --dir` refused for `..`, `.git`,
`.registry`. Controls (in-project file and symlink, hardlink) passed confinement and reached source preparation, where they were refused for
`identity_mismatch` because they are not the registered paper's PDF. SSRF: 53 must-block + 12 must-allow addresses,
numeric URL forms (`2130706433`, `0x7f.1`, `0177.0.0.1`, `127.1`), mixed public+private DNS answers, redirects to metadata/private/
http/credentialed/protocol-relative targets, 5-hop cap — all correct; two SIIT addresses leaked before fix #3.

**5. Search.** `scripts/test-live-search.ts`: 11 live queries, limits 1/5/10/20, OpenAlex-blocked, S2-blocked and all-blocked
(`SEARCH_UNAVAILABLE`). Before fix #1 every query carried `semantic-scholar: HTTP 404`; after it the warning is a real `HTTP 429`
from S2's shared unauthenticated pool (an upstream limit; `SEMANTIC_SCHOLAR_API_KEY` is optional per README).

**6. Registry/extraction.** `test-live-registration.ts` (batch of 3 → 2 registered + URL-form `duplicate` with preserved citekey;
bad identifiers typed `INVALID_DOI` / `DOI_NOT_FOUND`; 14/14 attached; identity-mismatch refused and original source kept; keyless
OA → `no_open_copy`). `test-live-tei.ts` PASS. `test-item4-extraction.ts`: avg 82.8 ms/doc; one 14-page paper takes ~225 ms, over the
handoff's "< 150 ms" bar (consistent over 4 runs; criterion miss, not a defect). `sync-bib`: garbage, deleted file and deleted
`refs/` all restored byte-identical; a hand-added entry is discarded (one-way); 3 runs give one sha256.

**8. Parity.** Lock sha256 `b5ce9d77…0d63`, size 333,590,944 = local `sha256sum` = Hugging Face `x-linked-etag` at the pinned
commit. `embed-parity.py` served with the lock's own `serverArgs`.

**9. Lifecycle.** `test-item5-rag-lifecycle.ts` PASS (incl. SIGKILL-the-child auto-restart, alien-port, truncated/corrupt cache
repair). Parent-signal probe through a real MCP session: stdin-close, SIGTERM, SIGINT, SIGHUP leave **no** `llama-server`.

## Bugs Discovered & TDD Fixes

Each fix has a regression test that was seen red for the right reason before the change.

1. **S2 URL** — `tests/scholarly.spec.ts` "requests each provider's documented search endpoint" built from `providerConfigOf`;
   red `'/graph/v1/graph/v1/paper/search'`. Fix: default base `https://api.semanticscholar.org`.
2. **`mcp install` data loss** — `tests/cli.spec.ts` "refuses, and leaves the file byte-identical…" (5 hosts × `[1,2]`, `"oops"`, `7`, `null`);
   red `actual: 0, expected: 1`. Fix: `serverTable()` helper replaces four copy-pasted ternaries; refuses with a message naming the key and file.
3. **SIIT range** — three addresses added to `blocked` in `tests/source-download.spec.ts`; red ×3. Fix: `["::ffff:0:0:0", 96]`.
   My first attempt wrote `::ffff:0:0` (= the v4-**mapped** prefix) and blocked every IPv4 address; the suite failed 20 tests immediately and it was corrected.
4. **tar cleanup race** — `tests/embed-runtime.spec.ts` stress case (200 iterations × 20 small entries + absolute member); red ~1 in 3
   runs, same `ENOTEMPTY`. Fix: drive `Unpack` directly, settle on `close` after an `error`; handle source read errors.
5. **Harness** — `scripts/test-item7-claim-verification.ts` now derives every denominator from the real sample sizes, prints the last
   progress step and adds specificity.

## Known Limitations & Next Steps

- **Search expectations in the handoff were wrong or unmet.** `10.1038/s41586-020-2649-2` is *Array programming with NumPy*, not
  AlphaFold. `search_papers` is documented as free-text ("a DOI-shaped query still searches"); DOI/arXiv-ID resolution belongs to
  `register`, so exact-ID queries returning other papers is by design. The misspelled query `attenshun is all you ned` did **not**
  return *Attention Is All You Need* even when S2 answered (top: "All You Need Is LSD"); OpenAlex/Crossref do no typo correction.
  Not verifiable further without an S2 key.
- **Eos margins are thin:** recall 90.5 % (bar ≥ 90), specificity 95.2 % (bar ≥ 95), precision 95.0 % (bar ≥ 95). The handoff's
  measured 95.0 / 96.7 / 97.4 % are not reproducible from the current script and sample. Run is deterministic (two runs identical).
  Treat as evidence, not a guarantee (README stance); there is no refutation verdict.
- **`llama-server` survives an uncatchable SIGKILL/OOM-kill of the host** (SIGTERM/INT/HUP are handled). The 2026-10-04 review's
  "eliminating orphaned server processes" overstates this. A fix needs a watchdog or `PR_SET_PDEATHSIG`-style mechanism.
- CLI `attach` / `register` exit 0 when the only item is refused (per-item refusals are outcomes by design); scripts must read the output.
- Not exercised: macOS/Windows runtimes (already BACKLOG §1), live S2 with a key, OpenRouter fallback engine.
- Hermes research was not used: every external claim was checked directly (HF headers, S2/OpenAlex endpoints, installed tar source).
